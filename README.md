# Huqiu Wedding City · 虎丘婚纱城

A high-end bridal field guide to **Huqiu Wedding City** (虎丘婚纱城) in Suzhou, China.

🌐 **Live site:** https://huqiu.wedding

## About

A self-contained, single-page static site. Everything — styles, scripts, and
content — lives in [`index.html`](./index.html). No build step, no dependencies.

## Hosting

Served via **GitHub Pages** from the `main` branch with a custom apex domain.

- `CNAME` — sets the custom domain (`huqiu.wedding`)
- `.nojekyll` — disables Jekyll so the HTML is published as-is
